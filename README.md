# RideMA

Ride-hailing platform for Morocco (rider-sets-the-price bidding). Start with `PROGRESS.md`, then `SPEC.md`.

| Folder | What |
|---|---|
| `backend/` | Node.js + TypeScript API, worker, public web pages |
| `admin/` | React admin panel |
| `apps/rider`, `apps/driver` | Flutter apps |
| `packages/ridema_core` | Shared Flutter code (brand, l10n, API client, auth screens) |
| `infra/` | Docker Compose, Caddy, OSRM, backups |
| `scripts/` | Deploy, backup, restore test, builds |
| `sim/` | Meknes ride simulator and load tests |
