# Security review — OWASP API Security Top 10 (2023)

Scope: `backend/` (REST + Socket.IO + public pages), `admin/`, Caddy config, mobile-app/API interaction. Reviewed by reading the code and by the tests named below (all in `backend/test/` unless stated). Status: ✅ addressed · ⚠️ accepted risk / needs a key or a decision.

| # | Risk | What we do | Evidence |
|---|---|---|---|
| API1 | Broken object-level authorization | Every ride/bid/receipt/offer/share/SOS/report route loads the object and checks the caller is its rider, its driver, a bidding driver (limited request view) or an admin; foreign objects answer **404** (no existence oracle). Admin file views require the admin role. Socket call signalling re-checks ride membership on every message. | `rides.test.ts › per-object authorization` (9 rider-side + 3 driver-side routes), `safety-realtime.test.ts › voice call … only between the two parties` |
| API2 | Broken authentication | Argon2id (OWASP params), constant-work on unknown emails; 15-min JWT (HS256, iss/aud checked, alg pinned) bound to a refresh family that is checked on every request (logout/block/reuse kill access within one request); rotating refresh tokens stored hashed with family reuse detection + abuse alert; idempotent retries don't trip reuse detection; login lock 10/15 min per email + 20/min per IP; 2FA (email code or TOTP, 5 wrong/15 min); admins forced to TOTP; password reset revokes all sessions; codes hashed, 5 attempts, single use. | `auth.test.ts` (17 tests) |

## Data protection extras
- ID documents and ID-check photos: AES-256-GCM per file, data key wrapped by `DOCUMENT_MASTER_KEY` (rotation: re-wrap keys only — `lib/crypto.ts › rewrapKey`); stored in a private bucket; MIME sniffed from magic bytes; every admin view written to an append-only access log. Only the last 4 characters of the CIN are stored. (`drivers.test.ts`)
- TOTP secrets encrypted at rest; idempotency responses (which can contain tokens) encrypted at rest and deleted after 48 h; email payloads in the outbox blanked after delivery.
- Append-only tables (DB trigger): `ride_events`, `consents`, `admin_audit_log`, `document_access_log` — only retention purges may delete.
- Logs redact passwords, tokens, PINs, TOTP secrets and authorization headers.

## Accepted risks / follow-ups (⚠️)
1. **Signup reveals whether an email exists** (`EMAIL_TAKEN`). Chosen for usability; rate-limited (10/h/IP). Revisit if enumeration is abused.
2. **Login lockout can be triggered by someone else** (10 wrong passwords / 15 min). Password reset still works during the lock.
3. **Play Integrity enforcement is off** until Play Console keys exist (BLOCKERS B11); mock-location and root checks are on.
4. **No WAF/CDN** in front of the single VPS; Caddy + rate limits only. Consider Cloudflare after moving to a real domain.
5. **Legal texts are drafts** — have them reviewed for law 09-08 and do the CNDP declaration before launch.
6. `npm audit --omit=dev`: backend 0 vulnerabilities; admin 0 (react-router upgraded to 7.18.4 during the review).
